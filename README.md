# 🌱 AgriMarket – Plataforma de Productos Agrícolas Locales

**AgriMarket** es una plataforma web diseñada para conectar directamente a pequeños productores agrícolas con consumidores, facilitando la comercialización de productos del campo mediante herramientas digitales.

El proyecto busca reducir las barreras de acceso a canales de venta digitales que enfrentan los pequeños agricultores, promoviendo el comercio local, la visibilidad de sus productos y una relación comercial más directa entre productores y consumidores.

---

## 🎯 Objetivo del proyecto

Desarrollar una solución tecnológica que permita a los pequeños productores agrícolas publicar y ofrecer sus productos, mientras que los consumidores pueden explorar el catálogo disponible, consultar productos y realizar solicitudes de compra de manera sencilla.

## 🚜 Problemática

Muchos pequeños productores agrícolas enfrentan dificultades para comercializar sus productos directamente debido a factores como:

- Dependencia de intermediarios comerciales.
- Dificultades para promocionar sus productos.
- Limitado acceso a canales digitales de comercialización.
- Poca visibilidad frente a consumidores potenciales.
- Barreras tecnológicas para implementar herramientas de venta en línea.

AgriMarket propone una alternativa digital que busca facilitar el contacto entre productores y consumidores.

## 💡 Funcionalidades principales

### 👨‍🌾 Para productores

- Registro de productores.
- Gestión de información del perfil.
- Publicación de productos agrícolas.
- Administración de información de productos.
- Disponibilidad de productos para consulta de consumidores.

### 🛒 Para consumidores

- Exploración del catálogo de productos.
- Búsqueda de productos por categorías.
- Consulta de información de los productos.
- Generación de solicitudes de compra.
